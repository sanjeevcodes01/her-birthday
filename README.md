# Sonaji Birthday Wish Website

## Open immediately on your computer
1. Extract `Sonaji_Birthday_Wish_Website_Photos_Flowers_Sounds_Final.zip`.
2. Open the extracted `Sonaji_Birthday_Wish_Website` folder.
3. Double-click `index.html` to open the birthday website in your browser.
4. Tap **♫ Play Darkhaast** to start the included background song. Browsers require a user tap before playing audio.

## Included
- `index.html` — website pages and birthday surprises
- `style.css` — responsive styling, falling flower petals, photo album and animations
- `script.js` — navigation, click sound effects, balloon interactions and music control
- `assets/photo1.jpg` and `assets/photo2.jpg` — the two supplied photos
- `assets/darkhaast.mp3` — the MP3 supplied for this personal birthday page

## Publish on GitHub Pages
Upload the *contents* of this folder (including the `assets` folder) to the root of a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The song and photos must be uploaded too. Public GitHub repositories make uploaded photos and audio publicly accessible; only publish files you have permission to share.
